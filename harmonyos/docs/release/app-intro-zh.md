## 2. 应用介绍（长描述，≤8000 字符）

> 以下正文共约 1,530 字符（上限 8,000），可直接整段粘贴到「应用介绍」字段。

GoGauge 是 OpenCode Go 的用量仪表盘：把配额窗口、Token 构成、模型消耗与请求明细集中在一屏，帮你在额度用完之前心里有数。

【核心功能】
• 配额窗口：滚动 5 小时 / 每周 / 每月三档窗口的已用比例、剩余额度与重置倒计时，进度一目了然。
• 用量概览：缓存命中率、缓存命中量、总 Token（含缓存命中）、总请求、总费用（含单次均价）、会话数 6 项指标，支持「今天 / 近 7 天 / 近 30 天 / 本周期 / 全部」时间范围切换。
• 今日趋势：24 小时输入 / 输出柱状图，快速定位用量高峰。
• 用量统计：Token 构成环形图（输入 / 输出 / 推理 / 缓存读 / 缓存写 / 会话数），模型用量环形图与排行（按输入 / 输出 / 费用切换，含请求数与缓存命中率），30 天费用 / 请求 / Token 趋势。
• 日历热力图：近 6 个月每日用量热力（可切换总 Token / 总请求 / 费用），并展示峰值、当前连续与最长连续天数。
• 模型用量趋势：近 30 天按模型堆叠的面积图，直观对比各模型走势。
• 使用记录：会话聚合与请求级明细双视图，支持按模型筛选、分页浏览，展示 Key 名称与单条费用。
• 多账号：添加 / 切换 / 重命名 / 删除 / 重新登录，用量按账号隔离，适合多个工作区或团队账号。
• 自动同步：前台支持 1 / 5 / 15 / 30 分钟定时增量同步，后台每 20 分钟增量同步；同步范围可选 30 / 60 / 90 / 180 天或全部，也可手动「立即全量同步」。
• 双主题与中英双语：亮色 / 深色一键切换，中文 / English 界面随时切换；美元 / 人民币货币切换。
• 多设备适配：适配手机、平板与 PC/2in1 屏幕形态，窄屏使用底部导航、宽屏使用左侧导航。
• 本地优先：所有数据保存在本机应用私有目录；登录凭证仅保存在本机数据库，仅用于访问 opencode.ai 官方接口，不上传开发者服务器；无广告、无统计 SDK、无内购。

【使用方式】
1. 打开应用，点击「立即登录」；
2. 在应用内打开的 opencode.ai 控制台登录页完成登录（需要你自己的 OpenCode 账号，并已订阅 OpenCode Go）；
3. 登录成功后自动保存会话凭证并同步数据，返回首页即可查看；
4. 可在「设置」中调整同步频率、同步范围、语言、主题与货币单位。

【系统要求】
• HarmonyOS NEXT（HarmonyOS 6.1.1 / API 24 及以上）
• 支持手机、平板、PC/2in1 设备

## 4. 分类 / 标签 / 年龄分级建议（填写依据）

- **一级分类**：应用（非游戏）。
- **二级分类**：`工具`（应用市场分类列表中的「工具」）。
- **标签**：主标签 `工具`，次标签 `AI`；如后台还提供 `安全性能`、`效率` 等可选标签，最多再选 1~2 个与“用量查看 / 效率”相关的即可，不要选广告营销相关标签（审核会核对标签与实际功能是否相符）。
